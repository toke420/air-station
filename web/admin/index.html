      Images View site ↗

      Every picture on the public site can be replaced. Each card shows where the picture is used and the size and format that fit best. Uploads replace the old file straight away; visitors see the change on their next page load. To move a whole look between stations, use theme packs: airctl branding export / import (docs/THEMING.md).

      Page texts

      Leave a box empty to keep the default (shown in grey). {station} becomes the station name and {year} the current year; *word* highlights a word in the accent colour. In the larger boxes each line becomes a new line on the page. Station name, tagline, about text and the banner genres are in Site settings.

      Colours

      The accent colour is used for links, buttons, icons and the player; the highlight colour for live badges, the Listen button and highlighted words. For anything else use custom CSS.

      Custom CSS and JavaScript

      Added to every public page (homepage and Live Video), never to this Studio, so a mistake can't lock you out. If the site looks broken after a change, open it with ?nocustom at the end of the address (e.g. /?nocustom) to see it without your code, then fix or clear it here. The CSS variables you can override are listed in docs/THEMING.md.

      Only add JavaScript you trust: it runs in every visitor's browser. Up to 100 KB each.

      Duplicate tracks

      Matches are by same artist and title (ignoring things like "(Official Video)", "[HD]", "feat." and "Remastered") or by identical file size. "Keep" disables the other copies so AutoDJ won't play them; nothing on your drive is deleted (the share is read-only). Use the paths to tidy the drive at home if you like.

      Licence …

      Deactivate before moving the station to a new server, then enter the same key there. A server that stops checking in frees its place by itself after 30 days.

      Enter your licence key

      Buy a licence

      The key is in your purchase e-mail. Activating sends the key, this station's domain and a random install id to the licence server; nothing else.

      No internet on this server? Use a certificate

      Send the seller your licence key, this domain and this install id; you'll get a certificate to paste here.

      Mixxx

      Preferences → Live Broadcasting → add a connection. When you press “Enable Live Broadcasting” the radio switches to you within a few seconds; stop it and AutoDJ comes back with a fresh track.

      OBS

      Settings → Stream → Service: Custom. SRT is recommended (better on shaky connections). Audio: AAC or Opus, 48 kHz. Start Streaming to go on air.

      Share your stream

      Addresses for apps, radio directories and IPTV playlists. Players that can't play the MP3 streams (many IPTV and TV apps) use HLS.
