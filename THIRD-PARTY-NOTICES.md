# Third-party software and data

AirStation's own code (the `app/`, `web/`, `scripts/`, `config/` and `docs/` folders)
is covered by [LICENSE](LICENSE). AirStation runs alongside the separate programs
below. They are **not included** in the AirStation download: Docker downloads them
from their publishers when you install, and each stays under its own licence.

| Component | Used for | Licence | Source |
|---|---|---|---|
| Icecast 2.4 (Debian package, installed in the AirStation image) | Streaming server | GPL-2.0 | https://icecast.org |
| Liquidsoap (`savonet/liquidsoap` image) | AutoDJ and live switching | GPL-2.0-or-later | https://www.liquidsoap.info |
| Caddy (`caddy` image) | HTTPS and web server | Apache-2.0 | https://caddyserver.com |
| MediaMTX (`bluenviron/mediamtx` image) | OBS ingest (SRT/RTMP) | MIT | https://github.com/bluenviron/mediamtx |
| FFmpeg (installed on the server with apt) | Checking and reading music files | LGPL-2.1+/GPL-2.0+ | https://ffmpeg.org |
| Debian 13 and Python 3 (base image) | Runtime | Various free licences / PSF | https://www.debian.org |
| NodeBB (optional community add-on) | Forum | GPL-3.0 | https://nodebb.org |
| Rauthy (optional community add-on) | Sign-on | Apache-2.0 | https://github.com/sebadob/rauthy |
| PostgreSQL (optional community add-on) | Forum database | PostgreSQL Licence | https://www.postgresql.org |

AirStation talks to these programs over the network or the command line and does not
include or modify their code. Their source is available from the addresses above.

## Data

- **DB-IP IP to City Lite** (downloaded by `airctl geoip update`): © DB-IP.com,
  licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Studio
  shows this attribution under the listener map.
- **Map tiles** in Studio > Listeners: © OpenStreetMap contributors (ODbL), served
  under the OpenStreetMap Foundation's tile usage policy; or CARTO basemaps under
  CARTO's terms if you choose them.

## Bundled images

The default images in `web/assets/img/` are generated by
`scripts/dev/make_default_images.py` and are part of AirStation.
